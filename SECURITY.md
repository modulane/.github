# Security Policy

## Reporting a Vulnerability

⚠️ **NEVER open a public issue for a security vulnerability.**

Use “Report a vulnerability” in the *Security* tab of the relevant repo
(private vulnerability reporting). Response within 72 hours.

## Supported Versions

Each repository lists its supported versions in its own SECURITY.md file.
Previous major versions receive critical patches
for 6 months after the release of the next major version. This may be changed at the discretion of the Modulane project administrator.

## SBOM

Each public release includes a CycloneDX SBOM. This may be changed with the approval of the Modulane project administrator.
