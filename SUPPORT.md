# Support

Modulane projects are maintained by one person alongside their own work, so help is given on a best-effort basis.

| I want to…                         | Where to go                                                             |
| ---------------------------------- | ----------------------------------------------------------------------- |
| Ask how to use a project           | Read the project's README, then open a question issue in its repository |
| Report a bug                       | Open a bug report in the project's repository                           |
| Suggest a feature                  | Open a feature request in the project's repository                      |
| Report a security vulnerability    | Report it privately, as described in the [security policy](SECURITY.md) |
| Report a code of conduct violation | Follow the reporting steps in the [code of conduct](CODE_OF_CONDUCT.md) |

When you ask for help, include the project's version, your operating system and the steps that led to the problem. It makes the answer much faster.

If a project saves you time and you want to support its development, see [Modulane on Patreon](https://www.patreon.com/modulane).
